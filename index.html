SVG → XML · ENGINE v2.0

Alight Motion Converter

Dua engine saja: Maximum Fidelity untuk hasil strict, dan Small Patch Cleanup untuk menghapus patch/island SVG yang sangat kecil tanpa merge warna, tanpa node reduction, dan tanpa menghapus stroke.

Pengaturan Small Patch Cleanup

Maximum Fidelity: z-order asli, native stroke, gradient, clipPath, group opacity, presisi 8, tanpa grouping dan tanpa node reduction. Output ditolak jika strict audit menemukan loss yang diketahui.

Small Patch Cleanup memakai pipeline Maximum Fidelity yang sama, lalu hanya membuang island/subpath di bawah ambang patch. Bentuk tipis yang cukup panjang dilindungi agar garis penting tidak ikut hilang.

ENGINE API v2

GET /api/v1/engines

Daftar engine publik dan bisa dibaca dari website mana pun.

GET /api/v1/convert?engine=small-patch-cleanup&svg=...

GET conversion untuk SVG kecil. Header x-api-key tetap wajib. Tambahkan &raw=1 untuk XML langsung.

POST /api/v1/convert

Disarankan untuk SVG besar. Body: { "svg": "<svg...>", "options": { "quality": "maximum-fidelity" } }
