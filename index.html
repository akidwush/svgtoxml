Alight Motion Converter

Dua engine: Maximum Fidelity untuk preservasi source dan Smart Color Groups untuk satu warna solid aman menjadi satu layer dengan audit paint, geometri, dan z-order.

Informasi engine

Maximum Fidelity: z-order asli, native stroke, gradient, clipPath, group opacity, presisi 8, tanpa grouping dan tanpa node reduction. Output ditolak jika strict audit menemukan loss yang diketahui.

Smart Color Groups memakai effective paint, actual path topology, dan graph z-order. Gradient, stroke, transparency, clip, mask, filter, dan compositing kompleks tetap menjadi fallback terpisah. Source path tidak digabung.
